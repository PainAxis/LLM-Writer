# 图谱备份与移动端导航

[English](graph-backup-mobile.md) | [简体中文](graph-backup-mobile.zh-CN.md)

本次第三阶段收尾覆盖实际作品的事实图谱备份，以及可操作的窄屏导航。不接入 Writer 生成上下文，也不展开第四阶段 Agent。

## 备份与恢复

在**设置 → 数据管理**选择**导出所有数据**或**小说数据**，两者都包含已提交小说正文与完整已存事实图谱。通过**选择备份文件**导入该 JSON，选中小说分类，确认后刷新页面。

版本 2 格式增加与 `data.novels` 配套的可选 `data.factGraphs` 字段。保留关系 ID、实体类型／名称、关系词、原文明示／模型推断、作者／模型创建来源、作者确认，以及全部章节 ID、SHA-256 原文修订、UTF-16 范围和精确引文。备份包含过期与未披露关系，并非只导出当前画布。因此备份文件含完整正文及后文信息；披露截止章节约束显示，不对导出文件脱敏。

恢复不会重新定位引文，也不会将旧锚点改绑到当前章节修订。图谱存储版本会更新，阻止恢复前打开的编辑页静默覆盖新状态。恢复后的章节标题／正文与依据修订不符时，关系仍被排除，作者确认也不例外；恢复完全相同的原始标题／正文可能使内容哈希锚点重新有效。多前提关系必须等全部依据披露后才可见。

| 导入内容 | 行为 |
| --- | --- |
| 小说与图谱字段 | 为导入作品恢复所提供的图谱状态，包括明确的空图谱 |
| 不含图谱字段的旧备份 | 恢复所选分类，保留已有图谱记录；仍执行当前原文校验 |
| 仅其他分类 | 不修改图谱 |
| 无效／跨作品图谱 | 写入任何所选数据前拒绝 |

图谱文档沿用正常存储的容量与关系数上限，拒绝未知作品 ID 和重复身份。遇到损坏的已有图谱，导出会失败而不会静默遗漏。图谱批量替换在一次 IndexedDB 比较交换事务中完成；可捕获的错误会尝试回滚，不覆盖并发修改。导入页完成后刷新；继续使用其他已开标签页前也应刷新。

仅覆盖导出作品集合中实际存在的小说。独立记忆示例与已删除作品遗留图谱不在范围内，普通 TXT／正文导出不包含标注。不识别 `factGraphs` 的旧版应用会拒绝新备份，请使用更新后的应用恢复。

小说与图谱恢复跨越现有存储系统，并非覆盖 localStorage 和 IndexedDB 的抗崩溃事务；中断、浏览器关闭或回滚失败时，可能需要保留的文件再次导入。替换前应备份。没有新增自动清理过期记录、历史章节浏览或跨设备同步。

## 窄屏操作

宽度不超过 768 CSS 像素时，导航默认关闭，从页头**打开导航**按钮展开。模态抽屉提供关闭按钮、遮罩关闭、Escape 和键盘焦点约束；选择页面后自动收起。抽屉打开时，背景页面不可操作。桌面继续使用原有展开／折叠导航。

记忆检索、关系表单、原文依据和设置备份控件在窄屏内换行，修订号与长引文不会撑宽页面。Cytoscape 画布之外仍提供等价关系列表。

## 复现验收

```bash
npm run smoke:backup
npm run smoke:graph-backup
npm run smoke:memory-fact-store
npm run smoke:memory-fact-graph
npm run build
npm run test:browser-graph-backup
npm run test:browser-mobile
```

独立 CI 作业在 Chromium 中运行生产构建，上传报告、截图和失败轨迹。备份测试执行真实设置页的下载／上传流程，移动测试实际操作控件和图谱。合成夹具及外部请求拦截使测试保持本地，不需要付费模型调用。

图谱备份核心测试往返恢复 600 章、1,411,959 个原文字符和 5,400 条关系（序列化备份为 3,700,899 个字符）。9 个备份浏览器场景使用三个独立上下文；16 个移动场景分别运行于 390×844 和 320×640。这些测试验证正确性和实际操作，不是性能基准。

结果以当前 PR 的 CI 为准。Chromium 视口／触控模拟不代表 Safari、Firefox、实体手机、软键盘或应用全部其他页面已通过验收。原有模型效果与检索容量限制仍适用，见[图谱约定](memory-fact-graph.zh-CN.md)和[超长篇测试](memory-stress-tests.zh-CN.md)。
