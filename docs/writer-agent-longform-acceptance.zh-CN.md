# 第四阶段最终验收：自主长篇创作

[English](writer-agent-longform-acceptance.md) | [简体中文](writer-agent-longform-acceptance.zh-CN.md)

状态：**验收规格，尚未实现或执行**。本次增量只交付[短例评测准备](writer-agent-evaluation.zh-CN.md)，不代表本项最终验收。本文件不批准服务商、凭据读取、付费运行或长任务编排。

## 最终结果与架构缺口

自主完成中文、英文各一部完整小说。每个创作任务必须依次产生**大纲 → 人设 → 细纲 → 章纲 → 小说正文**。每部目标为 **1,000,000 个正文字符**，不是英文单词；规划文档不计入。报告最终准确字符数及超出量，不为凑整截断完整结局。不足不能通过，填充和复制／重复凑数也不能满足目标。两部作品全书范围都必须在题材、剧情、人设和暗线伏笔上没有漂移。

[现有 Agent](writer-author-agent.zh-CN.md)不是这个架构。`writerAgentProtocol.ts` 最多允许两次模型请求、一次检索和 2,000 个 UTF-16 单位的草稿，提示词要求约 200–500 个汉字；依据需要作者逐条批准，授权只存在于会话中，没有长篇规划和修订循环。八个短例中的标准答案辅助选择也不是自主依据选择。反复调用现有 Agent 或提高上限不能建立本契约，更不能绕过现有授权边界。

后续至少需要以下工作，各自通过审阅和回归门槛：

- 单独授权、识别创作语言的任务状态机，有限地执行规划、章节生成、核验和修订。初始授权必须明确界定自动选择依据、章节提交、修订及服务商披露；现有人工审阅 Agent 保持原边界。
- 带版本的规划产物和原文可追溯的设定账本：题材约束、剧情／时间线、人物身份／动机／成长、人物知情范围与客观事实，以及有计划期限的铺垫／回收义务。作者知道未来计划，不意味着角色可以提前知道或正文可以提前揭露。
- 保留依据出处的记忆和上下文组装：取得所有相关前提，或明确停在未解决状态，不能把摘要、top-k 命中或相似度当作完整设定。新事实和有意的人物成长需要有依据的变化过程，不能在矛盾发生后改计划来豁免。
- 持久任务检查点、请求／预算预留、不可变章节版本、依赖失效和崩溃恢复。已有版本化 IndexedDB 正文存储、CAS 和提交回执是基础，并非不存在；缺口是任务重启归属、长任务资源表现及两部小说完整核验。第二阶段编辑器／存储重构仍独立，但不能借此推迟本项所需的任务持久化和规模测试。
- 独立全文审阅及绑定最终产物的无原文验收报告。现有本地／混合容量测试、模拟响应及短例结果，都不能代替经授权的真实模型完整创作。

## 冻结任务与可复现计数

运行前冻结本地清单：源码 commit/tree、实现与提示词 hash、计数／正文提取版本、Python 与 Unicode 数据版本、初始创作要求、语言、模型／服务商、生成参数、有限预算、修订规则、审阅流程、保留策略和任务 ID。保留自主选择过程以及四层规划产物的 hash、父版本关系，并在生成正文前冻结所得设定。实质设定变更必须产生新候选并使依赖证据失效，不能倒改失败记录。人工续写、导入现成小说或未披露的人工重写不属于自主产出；操作授权／故障恢复与创作干预分开记录。可复现指对保留产物、计数和证据重新核验，不承诺随机模型重新运行会产生相同正文。

只计每章最终接受版本的纯文本正文。章名、大纲、人设笔记、摘要、提示词、核验文字、废稿和元数据均排除。冻结并测试编辑器转纯文本的提取器；HTML 只解码一次，正确保留字面的实体字符串。每章分别记录提取原文及规范文本的 hash，不计人为添加的章间分隔符。产物根 hash 必须绑定有序章节 ID、修订、长度与 hash，不能使用有歧义的直接拼接。

主要单位为 **Unicode 标量值**，不是 UTF-8 字节、JavaScript UTF-16 单位或字素簇。拒绝未配对代理项；逐章将 CRLF／CR 转为 LF，再做 NFC 规范化。正常英文空格与正文换行计入，同时分别报告原始／规范文本中的空白及非空白字符数，不能暗改为百万非空白字符。冻结下列空白集合和 Unicode 规范化实现；规范化改变偏移时保留原文映射，生产依据仍使用准确的原始 UTF-16 锚点。

```python
import hashlib
import unicodedata

WHITE_SPACE = set(range(0x09, 0x0E)) | {
    0x20, 0x85, 0xA0, 0x1680, *range(0x2000, 0x200B),
    0x2028, 0x2029, 0x202F, 0x205F, 0x3000,
}

def measure_body(body):
    if any(0xD800 <= ord(c) <= 0xDFFF for c in body):
        raise ValueError("unpaired surrogate")
    def counts(text):
        encoded = text.encode("utf-8", errors="strict")
        spaces = sum(ord(c) in WHITE_SPACE for c in text)
        return {"scalars": len(text), "whitespace": spaces,
                "non_whitespace": len(text) - spaces,
                "utf16_units": len(text.encode("utf-16-le")) // 2,
                "utf8_bytes": len(encoded),
                "sha256": hashlib.sha256(encoded).hexdigest()}
    canonical = unicodedata.normalize("NFC", body.replace("\r\n", "\n").replace("\r", "\n"))
    return {"unicode_version": unicodedata.unidata_version,
            "raw": counts(body), "canonical": counts(canonical)}

sample = measure_body("A\u030A\r\n中😀 ")
assert sample["raw"]["scalars"] == 7
assert sample["canonical"]["scalars"] == 5
assert sample["canonical"]["whitespace"] == 2
assert sample["canonical"]["utf16_units"] == 6
```

两种语言分别汇总已接受章节的规范标量计数。另一独立实现必须对同一冻结产物复算，并覆盖增补平面字符、组合符、实体、空正文及换行测试向量；计数不一致阻止验收。重复段落／章节扫描与重叠指标只能提出候选，所有凑数／重复发现都须依据实际正文独立裁决。合理复现不自动判错，但未解决项不能通过；仅为达标插入的空白、不可见控制符、摘要或重复文字不算有效小说内容。

## 全书一致性证据，而非抽样

生成前冻结审阅标准。每种语言都由具备相应能力的审阅者核验，翻译摘要不能代替中文或英文原作。独立审阅者不能参与候选创作、继承作者自评分数或以“已成功”标签代替证据。记录实际审阅者身份／角色、适用的模型／版本、原文访问情况、利益冲突和方法；仅进程或模型名称不同，不证明独立性或判断正确。

每部最终小说都必须满足：

1. **正文覆盖：**按有重叠、绑定修订的窗口读取全部最终正文，不得漏区间、截断或因容量跳过。保留准确覆盖区间并集和已覆盖／总数。规划文档和全部章纲也须完整覆盖；记录实际原文访问，不能只记录摘要访问。
2. **设定及关系覆盖：**独立提取逐窗口核对事实、变化、承诺、知情状态及铺垫／回收线索，包括生成器账本没有的项目。必须与冻结设定及全量累计账本核对，不能只看相邻窗口。每项登记约束、人物／剧情轨迹及义务都要在应到节点和结尾明确裁决；跨章关系引用全部支持／冲突片段。新发现依赖扩展账本；遗漏、容量跳过及未解决关系都保留为覆盖缺口。
3. **四个明确维度：**题材规则／基调轨迹；剧情因果、时间线及承诺方向；人物身份、能力、动机、知情范围及有依据的成长；全部暗线铺垫、披露与回收。计划保留的开放线索必须在正文生成前就声明为有意开放，不能遗忘后改名。叙述不确定性／不可靠叙述与无依据矛盾要用引用证据区分。
4. **独立发现和裁决：**每项主张／发现保留稳定 ID、设定／正文 hash、准确原始及规范范围、理由和 `supported`、`drift` 或 `unresolved` 状态。所有分歧、疑似凑数及遗漏／模糊义务都须由独立于创作过程的审阅依据原文裁决，生成器自检只作诊断。修订后的最终版本必须重审；过期引用及受影响的后续判断失效，重新建立最终全书覆盖。
5. **核验对照：**两种语言均设置单独标记的植入漂移与干净对照，覆盖四个维度、远距离依赖、歧义证据和凑数。对照不属于两部小说，也不计篇幅。漏掉必要对照或覆盖统计不可靠会阻止验收，但对照通过也不证明文学真值。

全文窗口覆盖**不等于**所有语义关系已经穷尽。有限审阅无法证明任意文学真值或排除全部解释。本项是可证伪、绑定具体作品的证据契约，不是定理，也不把“没有漂移”弱化为别的指标。抽样、平均分、相似度阈值、生成器自证和“检测器没有报警”都不能得出 PASS。已知语义缺口或未解决疑问必须保持不通过，不能被 100% 正文覆盖率掩盖。

## 检查点、恢复与有限资源计划

每层规划和每个已提交章节都保存检查点，包含规范计数、设定版本、请求 ID、核验覆盖、未决发现及累计预留／用量。每部作品在首章及目标的 10%、25%、50%、75%、100% 设置无原文进展检查点，但不替代逐章检查。推进前解决新发现的一致性阻塞，或进入有限修订状态。失败候选与修订版本保留在尝试历史中，只有单独审阅的最终版本才能通过。

测试在预留后、已发请求但服务端结果未知时、正文持久提交前后、修订中、核验中和预算耗尽时重启；同时覆盖损坏／过期检查点、并发编辑、取消和存储失败。只能依据核实的清单和提交回执恢复。不得盲目重发结果未知的请求、重复追加、重置预算、复用过期依据或暗换模型。已知未提交的失败只能在冻结重试规则及剩余额度内恢复。人工创作修补破坏自主产出结论，纯操作暂停本身不破坏；暂停、未完成或结果不确定都不能通过。

批准的计划必须规定单次及累计硬上限：请求数、可强制限制的输入／输出／推理 token、耗时、序列化字节、本地存储、重试次数、修订轮次、金额及币种。发请求前预留，重启保留未决预留；超限前停止，预算耗尽不授权缩减覆盖。服务商上报用量、分词器估计及配置预留分栏记录；账单／用量缺失是未知，不是零。

不能编造 token／字符常数或价格。后续单独获准后，使用拟用模型／分词器，对**两种语言**执行小规模且明确受限的标定，覆盖开头、中段及长上下文条件；测量准确序列化输入 token、每个规范字符对应的可见输出 token、废稿／修订输出、提取／核验成本、延迟、用量完整性及服务商推理行为。标定不是最终验收，也必须计入支出计划。

语言 `L` 的可见正文输出预测为 `C_L × r_L × g_L`：`C_L = 1,000,000`，`r_L` 为实测每个规范字符的可见 token 数，`g_L` 为所有生成正文字符数除以最终接受字符数。规划、审阅、修订说明和对照输出另计。真实输入为**全部**请求的 `sum(tokenizer(exact serialized request_j))`，包括失败请求和重复上下文，不能只用小说篇幅估算。若 `N` 章每章 `b` 字符，朴素地反复发送增长的历史，仅历史就约为 `b × N × (N−1) / 2` 字符，尚不含指令和审阅。账本核对及跨窗口关系也要测量自身工作量，不能假称只需一次线性扫描。

金额依据服务商经核实的当前输入／缓存／输出／推理费率、计费规则及适用费用计算，避免重复计费；报告标定范围与假设，而非确定报价。若隐藏费用或缺失计量使批准的金额上限无法执行，就不能假定有上限而启动。任何真实试跑前都要取得端点／模型／披露／凭据使用及预算的明确授权，标定后另行批准完整任务；变更服务商、预算或披露范围需要相应授权。

## 保留、结论与发布

完整合成小说、规划产物、修订历史、带原文发现及私有审阅包只留本地，置于仓库／CI 附件收集范围之外并限制访问。启动前冻结保留期限和本地存储上限，备份也只留本地并控制访问。不保留凭据、原始认证头、隐藏推理或原始服务商响应封装；保留有限请求身份／用量元数据，不公开可重建请求／响应的集合。不得上传完整小说、私有包、备份或 trace。以后经授权向服务商处理明确披露的合成输入，与发布附件是两种不同动作；没有核实条款时不能声称控制了服务商保留行为。

公开证据仅含白名单内、无原文的任务／版本 ID、完整产物 hash、计数、预算／实测用量、核验统计及结论。本地权威证据必须能供获授权的独立审阅者访问，公开 hash 本身不证明审阅质量或内容真值。保留期届满、产物遗失或证据不可访问，只能使后续复核未知，不能重造通过结论。

- **PASS：**两部最终小说均满足篇幅／内容／自主要求；四层规划和四个一致性维度都有完整且当前的证据；确认漂移为零、未决发现为零、已知覆盖缺口为零；预算／恢复／完整性检查通过。准确实现版本还须独立代码审阅无阻塞及必要 CI 全过。单独 CI 通过不能授予文学验收。
- **FAIL：**最终提交候选存在确认漂移、无效凑数、篇幅不足、自主／完整性违规或其他已证实违反契约的事实。每次失败均保留，不被后续修订掩盖；修订候选须有新的明确结论。
- **UNKNOWN / NOT RUN：**创作／审阅未完、请求／提交结果不确定、证据／覆盖缺失、审阅分歧未决，或缺授权／资源。即使其他维度未知，已确认失败仍记 FAIL。未知和未运行均不得算作 PASS。
