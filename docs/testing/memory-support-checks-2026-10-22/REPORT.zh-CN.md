## 冻结的语义协议固定集

- 小说固定集共 33 例：25 个语义用例、8 个操作安全拒绝用例。
- 受控响应：支持 **12/12**、不足 **6/6**、不确定 **7/7**，8 个操作用例全部安全阻止。
- 26 个必要前提、27 条有效当前来源引用；引擎调用受控生成器 25 次，**真实模型调用为零**。
- 全部返回“不足”的变异策略错 **19/25**；全部返回“支持”错 **13/25**。正例必须经过生产解析器与引用映射，不能仅靠安全拒答过关。
- 实测受控引擎最大输入为 2,443 个 UTF-16 单位／2,579 个 UTF-8 字节；最大模型文本为 255 单位／369 字节。这些规模不是质量门槛。
- 机械引用有效不等于推理成立。固定集明确保留“引用有效但语义错误”的质量失败，不声称解析器可以发现全部幻觉。

原始摘要为 `memory-support-controlled.json`；固定集 SHA-256：`ebf0a7ea662e6ddd3e2079598954888cd553c72ae74c666691ae822704b20c2d`。

## 已配置、待执行的生产构建浏览器验收

新运行器要求 **52 个场景**：全部 25 个冻结语义用例贯穿生产解析、引用映射和可见 UI；格式错误／超限／断流／服务失败；过期来源与发布竞态；取消和迟到成功；独立核对问题；移动端布局，以及另行批准的 Writer 生成。

独立 `support-enabled-long-novel-v1` 配置含 **600 章／1,388,902 字符**，披露范围为 **599 章／1,388,828 字符**。精确依据在第 588、590 章；第 600 章是必须排除的未来信息哨兵。Lab 和章节正文生成、续写、润色三个入口都须启用支持检查。该容量／生命周期配置不增加 25 个语义用例的分母。

配置断言为：共 50 次支持请求、3 次写作请求、62 次已选来源传输；长篇配置单列 4 次支持请求、3 次写作请求、0 次检索服务请求、8 次支持来源传输。这些是等待 CI 实际执行的断言，不是虚构的通过测量。浏览器服务均为本地受控固定集，绝不调用真实 Go。

## 单独授权的 Go 尝试：未成功

七例合成**代码／文档**固定集与小说集独立。默认 mock 通过生产准备 → API → 真实 SDK → 协议／引用校验，7/7 通过；SHA-256 为 `6012bdccee930f3e8a260c430043d8b13fd08e44ae8cf1fc939b478878de9f1e`，见 `code-mock.json`。

单独获准的真实尝试使用用户指定的 `https://opencode.ai/inference/go/v1/chat/completions`、模型 `glm-5.3-flash`、默认推理；GO01 的总输出上限为 600 tokens。**仅发起 1 次尝试**，在 **688 ms** 后以 `transport` 失败，没有记录到 HTTP 状态，也未收到响应字节。没有任何用例得到语义判断；**GO02–GO07 均未运行**。没有重试、替换路由／模型、嵌入请求或小说文本发送；未自动消耗剩余六次额度。

传输层刻意不保存原始诊断，统一类别可能包含请求错误或响应中断。因此现有证据不能区分 DNS／TLS／网络原因，不能确认服务是否收到完整请求，也不能认定密钥或路由无效。官方文档路由与用户指定路由不同，但没有携带凭据探测替代路由。**没有真实服务成功、模型质量或浏览器 CORS 结果。**

用量不可得。失败本地账单中的 `0` 仅是占位值，**不是测得的零 tokens 或零费用**；请求输出上限不等于实际消耗。密钥仅经进程 stdin 传入并驻留内存，未进入日志／配置／文件，结束后清除；没有新增持久凭据或账户访问。保留报告不含密钥、headers、小说正文或原始推理。

`go-live-attempt.json` 原样保留，尝试内前后 205 文件摘要一致。随后构建唯一源码变化是前述自动生成的类型声明；`source-snapshots.json` 根据这一处差异独立重建原始真实尝试摘要与最终 mock 摘要，不把失败尝试重新标成后续源码的测试。
