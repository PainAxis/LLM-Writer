# 有界 CI 证据归档

测试仍生成完整本地输入和原始报告，并执行原有断言。独立的 `scripts/prepare-ci-evidence.mjs` 为 13 组附件准备归档，不修改测试结果、原报告、fixture、断言或分母。

仅允许 `scripts/ci-evidence-files.mjs` 中的精确文件名。全部测试报告 JSON 附件都是新生成的 `*.summary.json`，明确标注为派生摘要，记录原路径、字节数和 SHA256，**不是原始报告**。全书扫描、支持核对、Writer-memory、事实图谱、图谱备份报告中的请求集合仅保留有界标量元数据、大小、计数和哈希，不保留请求／响应正文，避免大量单条有界请求拼接还原全稿。其他位置必要的有限合成断言片段仍可作为证据，不当成完整备份附件。失败、控制台及 DOM 诊断的自由文本只保留大小／哈希元数据，因为较短的断言 diff 也可能包含完整小备份。

主 CI 与可选 browser-tunnel 工作流都使用该准备边界。tunnel 单独精确上传的 `preview-url.json` 仅含预览 URL 元数据，不是报告或备份；发布附件仍是构建后的应用 ZIP、校验和及构建元数据，不包含测试目录。

只复制指定 UI 截图。完整备份／回导／语料导出、下载文本、完整脑图导出图片及 trace ZIP 均不归档。准备步骤使用新的隔离目录，拒绝符号链接和无效 JSON，记录缺失输入而不伪造通过。上传须准备成功且任务未取消；诊断摘要上传成功不能把失败测试改为成功。

完整原报告与备份导出留在执行环境本地。GitHub runner 的本地文件只是临时文件，**不是持久备份**。此前保留的完整合成备份继续位于现有工程工作区的本地持久目录。本次修改既不上传该备份，也不删除已有远端附件。
