## 范围与保留保证

基线为已合并 PR #36 的 main：`760042683405760428688d1a7d7f0346e2ff77d3`。纯测量实现先于生产改动。唯一生产优化位于 `novelPersistence.hydrateContents`：首次异步等待前捕获章节与分片引用，调用 `idbGetMany`，等待事务完成并确认全部正文存在，然后回填章节并移除引用。正文缺失或事务中止时，不得发布只加载了一部分的来源。

不新增可复用的正文缓存。已提交元数据的稳定性检查、有界重试、待完成／失败保存处理与跨标签页协调继续生效。Writer 的每个新鲜度边界仍读取已提交来源。这是读取路径优化，第二阶段章级持久化和编辑器工作仍独立待办。

[精确编号召回](memory-mixed-query-recall.zh-CN.md)、[未验证的匹配提示与逐项选择依据](memory-evidence-review.zh-CN.md)、当前修订、披露截止范围、完整图谱前提、过期来源拒绝及可选服务授权均保留既有约定，不以数字分数宣称问题已有答案。嵌入、重排与外部服务继续分别主动启用。这个历史读取路径改动没有实现第四阶段 Agent；何时开始该工作由当前路线图界定。

## 有界语义成本

生产限制保持为 **2,000 个合格片段、32 MiB 的 Float32 缓存载荷、每批 32 个片段、最高 4,096 维及原有远程耗时预算**。缓存测试通过生产服务解析器处理确定性的全一向量，并在每次模拟请求前执行完整来源新鲜度校验。它测量容量核算与边界，不评估语义质量或真实服务延迟。

| 维度 | 2,000 个向量载荷 | 冷／热查 2,000 个片段 | 冷查正文／查询请求数 | 模拟响应 JSON |
| --- | ---: | ---: | ---: | ---: |
| 512 | 3.906 MiB | 950.295／25.039 ms | 63／1 | 2,103,060 字节 |
| 4,096 | 31.25 MiB | 1,512.383／48.714 ms | 63／1 | 16,446,228 字节 |

热查询、缩小及扩大披露范围复用合格向量，但仍请求查询嵌入。修改一个旧章后，嵌入一个替换片段及查询。禁用语义会清空向量，重新启用时重建全部 2,000 个。达到 **2,001 个合格片段**时，两档都明确回退完整的本地检索，**正文及查询嵌入请求均为零**，不会悄悄只索引前 2,000 个。这保留本地精确编号／伏笔召回，但放弃该次查询的语义召回。缩小披露范围可能重新满足语义条件，但会改变允许使用的剧情范围，必须由作者决定。这组测量关闭重排；另行主动启用重排后，仍可发送有界本地候选进行重排。

两种维度合计 268 次模拟请求，覆盖 8,002 个正文项和 14 个查询项，通过 268 次逐请求来源校验及 118 次精确来源检查，真实网络请求为零。缩小范围或超容量回退不会清空此前缓存的向量；常驻载荷是本次操作序列的参考核算，不是直接堆测量。Float32 载荷不含元数据、JSON、临时数组和关键词索引内存；合成 JSON 大小来自全一数值，不代表真实浮点响应大小。2,000 × 4,096 也只有 31.25 MiB，因此该工作负载**未覆盖** 32 MiB 字节限制驱逐。两个维度依次运行，不能作为受控的维度速度比较。

## 受控对照

正文加载容量 CI 任务在同一 runner 上，使用原始测量代码，按**基线、候选、候选、基线（ABBA）**顺序运行两个固定历史生产端点：优化前 `760042683405760428688d1a7d7f0346e2ff77d3` 与优化后 `7739cb0f6d020e4e05d0bff8d9d18f59f3d903c0`。这里的“候选”指冻结的优化后实现，不是最新 PR 引擎。每次针对单作品及附带无关作品分别创建新浏览器上下文。比较器要求语料、来源哈希、返回依据、修订、范围、所选依据块、评估、正文读取数量与 Writer 来源读取次数一致；仅改变事务组织方式。报告保留每次样本及中位数，不设置依赖机器的耗时通过阈值。

前述初始基线用于选择优化；最终前后数据来自配对运行，不跨机器硬比。验证状态以当前 PR 的 CI 和产物为准。

配对 **CI #106** 运行通过 **48 个来源样本、768 次测量及 64 条依据对照**。使用同一个 AMD EPYC 7763 runner、Node 24.21.0 和 Chromium 153.0.8010.12。基线固定为 main `7600426`；候选 `f763439` 是 PR 分支提交 `b55c68d` 的 GitHub 集成测试合并提交，并非另一项生产改动。生产依赖哈希确认仅 `novelPersistence.ts` 不同。初始 CI #105 基线使用不同硬件，不参与下列收益计算。

## 维护冻结的对照

这个 CI 对照是正文加载优化的冻结实验，不是自动跟随 main 的基线。现在同时固定两个生产端点：优化前 `7600426` 与优化后 `7739cb0`。原始测量代码、严格的 17 项依赖对照与基线／候选事务计数断言均不变。优化后的 main 已批量读取，不能替代优化前端点。

同时固定端点，是为了在后续改动记忆引擎等依赖时保留历史实验，而非放松当前生产验证：其余正确性、压力和浏览器任务仍执行受审修订，`ci-memory-cold-index` 另行负责当前实现与固定基线的评分优化对照。不得通过放宽依赖清单、改变预期依据或删除断言来恢复通过。新的优化须有独立审阅的测量与对照约定，不能改写本报告。

## 复现与验收

```bash
node --expose-gc --import tsx scripts/benchmark-memory-capacity.ts --profile=million --output=artifacts/memory-capacity
node --expose-gc --import tsx scripts/benchmark-memory-capacity.ts --profile=ten-million --output=artifacts/memory-capacity
node --expose-gc --import tsx scripts/benchmark-memory-capacity.ts --profile=semantic --output=artifacts/memory-capacity
node scripts/benchmark-memory-source.mjs --profile=all --output=artifacts/memory-source-capacity
npm run smoke:source-hydration
npm run test:browser-writer-memory
```

来源测量接受 `--source-root`，容量测量接受 `--engine-root`，可让相同测量代码导入独立基线检出目录。`ci-memory-capacity` 任务保留配对 Chromium 来源报告；上述新增 Node 索引与语义核算报告由所列命令在本地测量，既有 CI 压力任务仍运行各自独立的工作负载。报告记录环境、实现／测量代码／语料哈希、各阶段原始耗时、IO 计数及来源检查。CPU 和内存观测包含测量设施；进程最大 RSS 覆盖完整进程，采样堆可能遗漏同步峰值。Chromium 探针记录主页面堆观察值，不代表整个浏览器／Worker 峰值内存。

正文加载修订的历史回归配置包含 **80 组冒烟及 134 个浏览器场景，其中 Writer 记忆 21 个场景**。正文加载回归覆盖分片缺失、请求成功后事务中止、重复引用、键值捕获、元数据替换与垃圾回收、有界重试、待完成和失败保存，以及禁止复用编辑器缓存。新增构建后业务场景保留超过 2,000 个合格片段后的迟位精确编号召回，要求逐项批准，修改旧章，并贯穿 Memory Lab 与 Writer 续写验证当前修订、旧事实排除、伏笔保留与未来信息隔离。既有场景另行覆盖章节正文生成和润色；新增超容量场景不宣称另外两条入口已在同等规模复测。服务请求均捕获为合成请求，不代表真实模型的写作质量。

CI #106 的构建后 Writer 运行另行通过 **21／21 个场景**。新增续写流程使用 **600 章／2,486,774 字符**，披露 598 章／2,486,640 字符，始终得到 **2,374 个合格片段**。迟位编号位于剧情第 588 章，之前至少有 2,333 个片段。明确启用嵌入、关闭重排后，各阶段显示语义回退，**嵌入和重排请求均为零**。捕获的三次合成生成请求各只包含一条作者明确选择的当前原文，不含关系，`answerability: unverified`；独立来源哈希／范围、旧事实排除、远伏笔找回及未来信息隔离均通过。该场景耗时 68.319 秒。这是独立业务语料，不是来源计时的 142.3 万字符语料，其耗时不作为优化前后结果。未来信息隔离断言针对检索依据及所选生成上下文；作者自由图谱标注不会自动接受语义核验，沿用既有[图谱审阅规则](memory-fact-graph.zh-CN.md#标记的含义)。

在历史正文加载修订中，冷全量索引与新实例重建仍然昂贵；后续[冷索引报告](memory-cold-index.zh-CN.md)单独测量评分优化。全库正文加载、来源序列化、没有持久化索引快照、2,000 片段／32 MiB 语义上限与可回答性未验证仍是当前限制。[第三阶段有限完成契约](../ROADMAP.zh-CN.md#第三阶段完成契约)覆盖剩余语义策略、有引用的支持检查与全书已披露范围候选抽取，完成后开始第四阶段。第二阶段编辑器／持久化／共享摘要扩展仍独立。
