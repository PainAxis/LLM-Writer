# Body Evidence & Coverage v1：正文证据与覆盖

[English](writer-campaign-body-evidence.md) | [简体中文](writer-campaign-body-evidence.zh-CN.md)

**只校验来源与结构，不审定语义。** 本切片把真实已接受的 Campaign 正文修订连接到可复用、只读的本地声明提案校验器。引文吻合不证明声明为真、角色确实知道、叙述者可靠或伏笔已经回收。语义抽取、裁决、自主生成和全书审计仍为 **NOT RUN**。

它承接 [Planning Contract v1](writer-campaign-planning.zh-CN.md) 与既有 v2 仓储，不增加持久化证据账本、任务种类、请求、结算或 Writer 图谱写入。[最终长篇标准](writer-agent-longform-acceptance.zh-CN.md) 仍要求中英文各一部正文 1,000,000 Unicode 标量的自主小说与独立全书审查；短小固定夹具不满足此标准。

## 可复用的生产路径

进入 `/#/campaigns`，明确创建中/英文 **正文证据案例（3 章）**。新注册配置为 `planning-contract-v1-body-evidence-three-chapter`，复用九任务、先完成全部规划的依赖图与离线 step/恢复机制。创建不会执行任务。其正文目标严格由冻结的短正文推导，不是百万字符目标。旧案例在相同显式输入下保持原来的字面响应、依赖图和目标行为；新构建身份自然会改变新建清单/制品的哈希。

正文接受后：

1. 选择已接受的连续前缀第 1 至 K 章。
2. 明确加载固定提案示例，或编辑本地规范 JSON 草稿。
3. 点击 **校验本地提案**，调用生产 `previewBodyEvidence(campaignId, proposalText)`，不是仅供夹具使用的旁路。
4. 查看来源身份、精确引文、已供应/声明已检查的覆盖、包大小，以及醒目的**语义未审查**状态。

通用入口可校验针对当前来源的其他受支持封闭提案，不要求固定示例的句子或含义。只有可选的固定示例构造器检查其注册夹具的字面正文。即使编辑后的 producer 写着 `offline_fixture`，来源标签仍未认证。草稿与结果仅存于当前会话，不保存、不派发；原始草稿、证据包和带来源内容的观察不得成为 CI 上传制品。

新夹具包含与规划不一致的角色信念、被提议为不可靠的叙述者、声称学习/遗忘、跨章多前提回收，以及挂在有效引文上的错误解释。它们可以通过来源/结构校验，语义却仍未审查。这是边界测试，不是文学审查器已发现或解决问题的证明。

## 精确的原始正文锚点与身份

“原始”仅指已接受并不可变的 `CampaignArtifact.text` 存储字符串，不指不可得的接受前模型/编辑器文本。这里不再规范化。每个锚点必须指向当前有效、已接受的正文制品，包含原始 UTF-16 半开区间、精确字面引文及其 UTF-8 SHA-256。错误引文/哈希、旧或异源修订、未接受来源、前缀外引用、非法区间、拆开代理对的端点一律拒绝，不模糊重定位。

正文前缀根绑定清单与当前候选、完整规划根、K，以及按章排序的精确来源引用、任务修订、制品候选沿袭和存储文本度量，不拼接正文来构造歧义哈希。当前有效制品可以合法保留历史候选 ID；只比较当前候选字符串不是来源证明。来源表完整供应每章的精确身份一次，包内锚点与覆盖行使用经过检查的表索引。

编译前后各进行一次新鲜、完整验证的仓储读取，检查运行时/源码身份、过期、取消及最终原始 head 完全相等。旧运行时/源码身份创建的 Campaign 仍可检查，但不能在新构建下获得预览或执行许可；请明确创建新案例来运行当前路径。返回的 head 只是当时观察，不是持续能力，也不声称实时订阅跨标签页变化。后续执行不能复用它作为授权。

v2 哈希、计数算法及已存字节保持不变。原始 UTF-16 偏移不同于标量计数、NFC 和换行规范化；既有 v2 与最终长篇规范对单独 CR 的处理差异不被偷偷修复。未来规范化抽取必须单独版本化，并提供明确的原始偏移映射。

## 封闭提案与完整的已声明前提

规范 `campaign-body-evidence-proposals-v1` JSON 仅支持固定字段和本地作者预览用途。未知字段/版本、重复键、非法标量和非规范编码都拒绝，不修复。

支持五种**提案**：

- **世界断言**：肯定或否定的提议，不是世界真相。
- **角色信念**：精确规划角色、规划事实主题及声明的态度；主题绑定不证明正文与规划语义等价。
- **叙述者声明**：声明与提议的可靠性标签，不是可靠性裁决。
- **角色变化**：有正文锚点的前后提案、精确规划角色和变化类型；知识变化两端保留同一持有者与主题。
- **铺垫/回收**：保留全部 setup、payoff、context 前提和用于比较的精确规划义务。

所有提交的提案与锚点都会保留。缺失前提、类型不合、支持环、叙述位置向前引用或闭包超预算，都会拒绝整个包。位置规则仅校验所声明的线性叙述顺序，不推断故事时间、真实因果、学习或人物动机。必要闭包中的未来作者规划仍是规划意图，不受正文位置排序限制。

v1 不解析新出现的正文角色/实体身份。无法表示的类型化主题或义务会明确拒绝，不静默丢弃，也不虚构规划身份。自然语言歧义、未声明依赖和语义矛盾无法靠这些检查发现。

所需规划记录保留完整值及全部传递注册引用。省略的可寻址全局记录与省略的章纲/场景文本分别计数。完整规划根绑定章纲，不等于章纲文本已经供应。禁止通过排序筛选、摘要、缩短引文或 top-k 回退丢弃必要前提来适配预算。

## 四种不同的观察

| 观察 | 含义 |
|---|---|
| **可用前缀** | 已接受第 1..K 章及其原始 UTF-16 分母；仓储读取不是语义检查。 |
| **已供应** | 真正序列化进包的原始引文区间并集与逐章缺口；哈希和元数据不算正文。 |
| **生产者声明已检查** | 未认证声明，仅校验区间与来源；区间必须包含在已供应并集中。没有声明就是 NOT RUN。 |
| **语义审查** | 永远为 `not_reviewed`，已审查单位为零，关系完整性 `not_assessed`。全文供应/声明检查不能提升此状态。 |

已声明前提闭包可以完整，语义关系却仍不完整。没有综合覆盖百分比、“无漂移”分数、事实成立标记或语义 PASS。唯一支持的暴露范围为 `local_author_only`；不支持面向读者、角色或提供方的上下文请求。作者能看到未来规划不意味着允许披露或角色已经知道。

## 生命周期与有限预算

同一引擎的规划/正文预览共用一个有界所有者，与持久执行 Run 分开。新预览取代旧预览。编辑、前缀切换、加载示例和刷新只撤销预览；既有切换 Campaign、创建或显式停止时撤销 Run 的行为不变。异步示例加载还会校验 Campaign、K、编辑版本和独立所有权，不能覆盖更新的草稿。

每次异步预览读/编译等待都响应取消，限时为 3 秒和单次总 10 秒剩余额度中的较小值。哈希及有界同步工作前后检查所有权/时限；不假装计时器能抢占同步 JavaScript。取消或超时后迟到的 promise 不得发布结果。不新增时间额度、碰运气重试或针对变化来源自动重编译。

新上限（总量约束优先）：

- 提案和完整序列化包各最多 **65,536 UTF-8 字节及 65,536 UTF-16 单位**。
- 60 个来源、128 个提案、256 个引文区间、256 个检查窗口和 1,024 次显式/载荷引用。
- 普通引用字段最多 16 个；setup/payoff 各 1–8，context 0–16；单条引文最多 8,192 UTF-16 单位，声明最多 512。
- JSON 深度 12、节点 16,384；原规划记录/引用/大小约束不变。

各维最大值不能保证同时装入。超限就是拒绝，不截断。既有 128 任务、64 MiB W+U+P、1 MiB 记录、3 秒 IO、5 秒夹具派发与 10 秒 action 上限都不提高。预览不新增请求或持久操作预算。

## 验收与证据边界

以下门槛独立于既有规划、Campaign、Writer Agent 和百万标量几何测试：

- 封闭协议、精确来源/Unicode 锚点、类型化多前提闭包、区间并集/补集、确定性序列化及 cap/cap+1。
- 真实生产仓储/引擎通用输入路径，实测零预览写入/提供方入口；旧来源、替换、损坏、取消、过期、超时、迟到完成及冷重开。
- 双语九任务原生 IndexedDB 与真实构建版 Lab 编辑器/预览，包括中断和重复操作。受限云环境本地原生测试为 NOT RUN；只使用获准 CI 的原生证据。
- 中英文分别在 Node 注入 IO 与原生 IndexedDB 跑 N60：123 个真实提交任务、完整短前缀供应/声明检查、远距离声明支持、新鲜读/编译度量、不变的存储/预算及冷重开。几何或合成包尺寸不能代替运行。
- 封闭无来源内容报告/归档、独立精确源码树审阅、完整回归、必要 exact-head CI 和独立合并 main 验证。

本文规定行为与门槛，不自行宣称已完成。报告须保留失败/未运行状态、精确分母和源码/core/harness/profile 身份；能力预期与实际权限计数分开，常量零不替代观测。不包括真实模型、凭据、提供方授权、自主抽取、持久裁决或修复循环。
