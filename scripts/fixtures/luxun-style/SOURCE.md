The main instructions describe concise, restrained satire, pointed analogies,
contrast, and forceful endings. The upstream package also offers
`references/research.md` for historical/background checks and
`examples/demo-conversation.md` for full interaction examples. These optional
Markdown resources were reviewed but are not included or used in this text-only
trial: the main instructions suffice for drafting from supplied fictional facts.
This trial imports only the unmodified `SKILL.md` through the application, so it
does not expose reference tools or require model tool calls. No upstream installer
or executable code is run.

The trial compares writing with the Skill disabled and enabled, using the same
prompt and facts. It measures integration and observable stylistic differences,
not author authenticity, literary equivalence, or universal writing quality.
Upstream literary claims and quotations are third-party test data, not verified
research findings; the trial does not ask the model to reproduce those quotations.
